# README demonstrations

These GIFs were recorded from the project's real Preview, Toolbar, and Settings Vue components with local Spine, background, and WAV assets. The recording harness uses a local HTTP adapter for the desktop file bridge. The animation and interaction code is unchanged. A brief click ring makes pointer clicks visible.

| File | Demonstration | Duration | Size |
| --- | --- | --- | --- |
| standing-display.gif | Paused Lathel illustration and costume background toggle | 3.4 s | 1.0 MiB |
| standing-interaction.gif | Character taps, motion returning to idle, and random voice triggers | 4.2 s | 2.0 MiB |
| skill-cutscene-audio.gif | Justia's default game cutscene with audio status and pause/resume | 8.3 s | 6.4 MiB |

All GIFs loop and are 800 pixels wide. GIF has no audio track; the application plays the separately supplied local audio. The recordings verified two standing voice triggers and five skill audio source starts.

The source recordings and runtime test logs remain outside the repository. Character artwork and game media belong to their respective owners.
